# Custom qBittorrent Image

Questa directory contiene la definizione per la build dell'immagine Docker personalizzata per **qBittorrent**.

## Scopo
Utilizzata per personalizzare l'immagine pubblica di qBittorrent (es. `lscr.io/linuxserver/qbittorrent`), permettendo di estenderla con script personalizzati, utility di automazione o configurazioni specifiche per lo stack Servarr.

## Struttura
- `Dockerfile`: Configurazione di build basata su un'immagine pubblica.
- `README.md`: Documentazione della personalizzazione.
