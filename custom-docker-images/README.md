# Custom Docker Images

Questa directory raccoglie i sorgenti per le immagini Docker personalizzate utilizzate nell'infrastruttura `pindaroli-arr-helm`.

## Scopo
La struttura in questa cartella viene impiegata per estendere e personalizzare immagini Docker pubbliche (es. da LinuxServer.io o dalla community), aggiungendo script custom, utility di sistema o configurazioni avanzate non incluse nelle immagini upstream.

## Immagini Disponibili
- [`custom-qbittorrent`](./custom-qbittorrent/): Immagine customizzata per qBittorrent.
